# Scribe 1.0.3

- Customize folder appearances with icons, colors, and emojis stored per notes library.
- Zoom the interface resolution in and out (`⌘+`, `⌘-`, `⌘0`) from the **View** menu or **Settings**, with saved zoom state and aligned window controls.
- Adjust the main note viewer font size (`12px`–`26px`, defaulting to `14px`) from **Settings** or the **Format** menu (`⌥⌘+`, `⌥⌘-`).
- Streamlined the toolbar and **View** menu by removing the unused writing focus toggle.
