# Scribe 1.0.2

- A unified toolbar, clearer note previews, scoped library search, and a quieter writing focus mode.
- Improved keyboard navigation, menus, link editing, and restoration of your cursor and reading position.
- Search highlights preserve word spacing in Hebrew, English, and mixed text.
- Updated title-bar double-click handling for window resizing.
- Tasks stay in place by default, with completion progress, hide/show completed, and optional sorting.
- Consistent list continuation, indentation, and comfortable caret visibility while writing.
- Reorder whole tasks with drag handles or keyboard arrows, with accurate drop guides and correctly anchored Hebrew drag previews.
- Formatting preserves the selected text and clearly shows its current style.
- Notes and attachments remain interoperable Markdown files with relative attachment links.
