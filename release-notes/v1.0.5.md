# Scribe 1.0.5

- Fixed Option+Backspace on a checklist item's only word starting a new line instead of deleting the word.
- Backspace and Delete now behave predictably at the start or end of bullets, numbered items, headings, code blocks and the line after a list.
- Typing `- [ ] ` starts a checklist; Enter in a table cell adds a line break; Tab and Shift+Tab indent code lines.
- Text typed after a link or inline code no longer joins it, and links whose text is their URL stay in sync when edited.
- Smart quotes stay straight after Hebrew letters (geresh and gershayim) and inside math; `×`, `«` and `»` substitutions are off.
- Notes keep their Markdown on save: line breaks, blank lines, unsupported HTML, table alignment, callout titles, image titles and headings 4–6 are preserved, with far less needless escaping.
- Edit ▸ Undo and Redo use the editor's history; Cmd+Backspace in text deletes to the line start instead of trashing the note.
- Added an automated editing suite (`npm run test:editing`) covering about 620 English and Hebrew editing cases.
