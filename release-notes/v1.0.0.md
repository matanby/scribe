# Scribe 1.0.0

The first release of Scribe for macOS: a visual Markdown editor that keeps notes as standard Markdown files and handles right-to-left Hebrew and left-to-right English in the same document.

## Downloads

- [Apple silicon](https://github.com/matanby/scribe/releases/download/v1.0.0/Scribe-1.0.0-arm64.dmg)
- [Intel](https://github.com/matanby/scribe/releases/download/v1.0.0/Scribe-1.0.0-x64.dmg)

## Install

Open the DMG and drag Scribe to Applications. The app is not notarized by Apple, so macOS may ask you to confirm the first launch. Control-click Scribe, choose **Open**, then confirm. If needed, use **System Settings → Privacy & Security → Open Anyway**.

## Requirements

macOS Big Sur (11) or later.
